Overview

概述

◎

目标

  • 多课程、多书籍的灵活内容组织
  • 学员注册、分班、考勤管理
  • 作业布置与批改
  • 视频教学安排（直播 / 录播）
  • 正式考核与评分
  • 学习进度追踪与互动功能
  • 教师评语与结业证书
◈

核心需求

  • A = 核心数据层（用户、课程、书籍、班级、注册、进度）
  • B = 考勤系统（课时、出勤、统计）
  • C = 作业系统（布置、提交、批改、反馈）
  • D = 视频教学（直播 / 录播排期、观看追踪）
  • E = 考核系统（题库、在线考试、评分）
  • F = 成绩管理（构成、加权计算、最终成绩）
  • G = 互动功能（高亮、评论、提问）
  • H = 评语与证书（教师评语、结业审批）
◇

技术栈

  • Cloudflare Pages Functions (ES Modules)
  • Cloudflare D1 (SQLite)
  • Vanilla JS + HTML/CSS
  • Cloudflare KV（缓存）
  • Cloudflare R2（视频存储 / 外部链接）

Architecture

架构

数据库选型

Cloudflare D1 (SQLite) — 免费额度 5GB，原生集成 Pages Functions，关系型数据，零运维

架构模式

模块化单体 (Modular Monolith) — 规模匹配 100–5000 学生，单数据库单部署，模块边界清晰

高亮锚定

W3C 双选择器 (TextQuote + TextPosition) — 快速路径 <1ms，稳健路径 5–30ms

扩展策略

KV 缓存学习会话，R2 存储视频资源；33 张表共享一个 D1 实例，模块边界清晰，可按需拆分

Deployment: Dual-Project

Blog (static, organicchurch.dpdns.org) and Course System (D1+Functions, learn.organicchurch.dpdns.org) deployed independently

Course Vanilla JS + HTML/CSS — 课件 SPA · 阅读器 · 同步模块 · 视频播放器
API Pages Functions — auth · books · courses · classes · attendance · assignments · videos · assessments · grades · students · interactions
Database Cloudflare D1 — 33 tables (SQLite), 12 domains
Cache Cloudflare KV — session buffering
Storage Cloudflare R2 — video assets, attachments

Business Flows

业务流程

流程 1 · 课程创建流程

管理员创建课程
添加书籍 (books + book_chapters)
创建课程内容单元 (course_items，关联 book_chapters)
配置成绩构成 (grade_components)
分配课程到班级 → 自动创建 enrollments
教师布置作业、创建考核、安排视频课时
课程发布 (status = 'published')

流程 2 · 班级分配课程 → 自动注册

班主任创建班级 "2026春季班"
添加学生 A, B, C 到 class_members
分配课程 "家教会的本体论" 到 class_courses
系统自动创建 enrollments (A/B/C → 课程)

流程 3 · 考勤流程

班主任/教师创建课时 (class_sessions)
课时日期到达，开始上课
教师逐个记录出勤状态 (attendance_records) — present / absent / late / excused
考勤数据进入成绩计算 (grade_components type='attendance')
学生可查看自己的考勤记录

流程 4 · 作业流程

教师创建作业 (assignments, status='published')
学生看到作业列表，开始作答
学生提交作业 (assignment_submissions, status='submitted')
超过 due_date → status 自动变为 'late'
教师查看提交列表，逐个批改
教师填写分数 + 反馈 (assignment_grades)
submission.status → 'graded' → 'returned'，学生查看成绩和反馈
作业分数进入成绩计算

流程 5 · 视频教学流程

教师/班主任创建视频课时 (video_lessons)
录播：上传视频 URL → status='completed'；直播：设置 scheduled_at + meeting_link → status='scheduled'
直播开始 → status='live' → 学生通过 meeting_link 加入
直播结束 → status='completed'
学生观看视频 → 实时更新 video_watch_logs (断点续播、观看时长)
视频观看数据进入成绩计算 (grade_components type='video')

流程 6 · 考核流程

教师创建考核 (assessments, status='published')
添加题目 (assessment_questions) — 客观题设置 correct_answer，主观题需手动评分
到 available_from → 学生开始考试 (assessment_submissions, status='in_progress')
学生逐题作答 (assessment_answers)
学生提交 / 时间到自动提交 → status='submitted'
系统自动评分客观题 → 教师手动评分主观题
计算总分 → status='graded' → 学生查看成绩
考核分数进入成绩计算

流程 7 · 成绩计算流程

课程配置成绩构成 — 例：作业 30% + 考核 40% + 考勤 15% + 视频 15%
各模块产生分数（作业平均分、考核总分、出勤率、视频完成率）
系统按 weight 加权计算 → total_score
按评分标准映射 → letter_grade (A/B/C/D/F)
final_grades.status = 'calculated'
教师审核 → status = 'approved' → 学生查看最终成绩
满足条件 → 可申请结业证书

流程 8 · 高亮渲染流程

页面加载
获取当前章节所有可见高亮
快速路径：用 position 定位 → 验证文字匹配 → 完成 (<1ms)
降级路径：搜索 quote.exact，用 prefix/suffix 消歧 (5-30ms)
找不到 → 标记为失效，不渲染

流程 9 · 结业审批流程

学生完成所有必修内容 (progress 100%)
系统提示 "可以申请结业"
学生点击"申请结业" → 创建 certificate (status=pending)
教师收到通知
教师查看：学习进度 + 作业成绩 + 考核成绩 + 考勤记录
教师批准 → status=approved, issued_at=now()
学生收到通知 + 证书可下载/打印
