# ADR-010: 博客分类改为二级分类树

> Status: Accepted | Date: 2026-09-26

## Context

博客分类原为单层平铺，41 个分类混用了多个维度（主题、圣经书卷、系列/课程、作者来源、学科），且长尾碎片化（18 个分类仅 1-3 篇）。用户要求改为二级分类。经 brainstorming 确认：一级=主题领域，二级=子主题/系列；多标签（一篇可属多个二级、可跨一级）；侧栏用可折叠树。

## Decision

- 新增 `brianinchrist/organicchurch/posts/categories.json` 作为分类树唯一真源，6 个一级：
  - 教会与实践：有机教会 / 教牧神学 / 门训与使命 / 课程与教育
  - 圣经与神学：圣经神学 / 神学 / 神学讲座 / 国度神学
  - 书卷与释经：创世记 出埃及记 利未记 摩西五经 马太福音 马可福音 路加福音 罗马书 哥林多前书 加拉太书 歌罗西书 彼得前书 但以理书 登山宝训
  - 灵命与生活：灵命塑造 / 信仰生活 / 心灵重塑
  - 社会与政治：基督徒的政治观
  - 人物与资源：观念 / Frank Viola / N. T. Wright / 精选
- `posts.json` 每篇的 `categories` 只存**二级叶子名**，多标签保留；`eyebrow` 重算为 `categories[0]`（原语义即"首分类"）。
- 合并规则：门徒栽培/BILD门训/大使命 → 门训与使命；课程/教育 → 课程与教育；圣经书卷 → 摩西五经；圣经研究 → 圣经神学；未分类(7241) → 精选。
- `index.html`：加载 `categories.json` 渲染可折叠树；一级可筛整棵子树并展开，二级精确筛选；计数一级=子树去重文章数、二级=含该叶子文章数；≤1024px 仍保持纵向列表（移除原横向换行覆盖）。
- `posts/assets/js/post-viewer.js` 零改动（继续把叶子名渲染成标签）。

## Consequences

- 新增文章必须使用树中已有的**叶子名**；新增分类须先加进 `categories.json`。
- 一级计数跨域文章会重复计入（多标签固有），子级计数之和可大于总数。
- 7241「下载摩斯」为 APK 下载占位页，按确认归入 `精选`，语义偏弱，待用户后续删除或归位。
