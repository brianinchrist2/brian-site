# Project Glossary
> Last updated: 2026-07-23

| Term | Definition |
|------|------------|
| **Scriptorium** | Design system name — warm parchment palette, serif/sans serif typography |
| **Oikos Church** | Source content directory for books (book2) and courseware (`oikos_church/{en,zh}/`) |
| **Organic Church** | Blog name — lives at `brianinchrist/organicchurch/` |
| **course-app** | Course management application with CF Pages Functions backend |
| **USERS_KV** | Cloudflare KV namespace storing user account data |
| **D1** | Cloudflare's SQLite-based relational database (used by course-app) |
| **posts.json** | Blog post metadata index (~2500+ entries) |
| **CF Pages Functions** | Cloudflare's serverless functions (ES Modules, Workers runtime) |
