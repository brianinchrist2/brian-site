## 核心要求：丰富，而不是铺满
- **总 12–18 张**；每讲 3–5 张。
- **不是每页都要图。**只挑"这张图能让这一页明显更好"的位置：
  - 该页是段落分隔/开场/收束，需要一张气息图；
  - 该页只有文字，缺一个视觉锚点；
  - 该页现有的 SVG 是纯装饰/概念示意（**可以**替换）；
  - **禁止**动承载数据或流程的页：时间轴、对比矩阵、流程箭头、路线图、网络结构图、漏斗/金字塔↔渔网、六问清单、术语图鉴这类。
- **风格必须多样**：至少用 4 种不同风格（见下风格池），风格要与内容匹配，而不是同一种滤镜套到底。
- **尺寸/位置必须多样**：至少用 3 种不同 slot（见下）。
- 全篇不许出现画面内文字（模型会写成乱码）——**包括"图纸标注""地图地名""书页文字"**，这类风格要显式禁止文字。

## 可用的 5 种 slot（只用这 5 种；尺寸是**生成像素**，都已能被 16 整除，别改）
| slot | 生成尺寸 | 画幅 | 在版面里怎么用 | 适合的内容 |
|---|---|---|---|---|
| `full` | 896×512 | 1.75:1 | 左栏整栏（替换该页 SVG 图解位） | 主视觉：历史现场、空间、场景 |
| `tall` | 512×768 | 2:3 竖 | 左栏竖构图（替换该页 SVG 图解位） | 竖向物件、牌匾、柱子、树、家谱线 |
| `wide` | 896×240 | 3.73:1 | 内容区顶部横幅（横跨全宽） | 开场/分隔/收束的气息图：地平线、长桌、道路、城墙 |
| `half` | 640×512 | 1.25:1 | 右栏文字下方，与文字并排 | 补充说明式的图：物件特写、手稿、器物 |
| `spot` | 512×512 | 1:1 | 右栏内的小图/页角装饰 | 小符号、印章、器皿、种子、果实的特写 |

- 尺寸是硬约束（≤0.5MP、长边≤896，控制本机出图耗时）。**不要**自行改尺寸；若某页确实需要别的画幅，也只能在这 5 种里选。

## 风格池（至少用 4 种；英文锚定词直接写进 prompt；风格要与"这一页在讲什么"匹配）
1. **铜版画/木刻 engraving / woodcut**——黑白排线，最贴羊皮纸底，投影对比强。适合：历史段落、审判/拆毁/建造类主题。
2. **东方水墨淡彩 ink wash / sumi-e with light color**——留白多，适合属灵、安息、内里生命类主题。
3. **手工建筑图纸 architectural drawing / ink and wash technical illustration**（**严禁任何标注文字**）——适合：Oikos 的空间、客厅/中庭、家教会启动路线。
4. **单色版画/剪纸剪影 silhouette / monochrome linocut / paper-cut**——无脸、干净、可做小尺寸 spot。适合：人物群像（以免画脸）、网络、倍增。
5. **小幅水彩 watercolour wash on toned paper**——柔和的暖灰调，适合爱宴、家庭、日常。
6. **抽象几何构成 geometric constructivist composition**——纯形与色块，适合概念页（加法↔乘法、三角、简洁↔复杂）。
7. **古地图/地形图 cartographic map**（**严禁地名文字**）——适合：扩张、网络、跨区域联结。
8. **泥金装饰手抄本边饰 illuminated manuscript ornament**（纯纹样，**无文字**）——适合：section 分隔、封面式页。

## 本机引擎的硬性限制（设计时必须绕开，否则一定返工）
- 引擎是 **FLUX.2-klein 4B**（蒸馏、小尺寸出图）。**不要**设计需要密密麻麻细节的画面。
- **近景人脸必定糊**、**手部多指高发**：主体不要是正脸特写或前景的手。人物一律用背影/远景/剪影/群像处理。
- 画面里**绝对不能有文字**（含中文、英文、题字、印章文字、书页字、地图地名）。
- 避免现代物件（电灯、塑料、玻璃幕墙、手机、电线、金属脚手架）。
- 出图会偏暗：prompt 里主动加 `well exposed`, `lifted shadows`, `clear midtones`。

## JSON schema（严格遵守，字段齐全）
```json
{
  "plan_version": 1,
  "rationale": "≤120 字：整体的配图策略（怎么分配风格与尺寸）",
  "images": [
    {
      "id": "l1-01-chengshi",
      "lecture": 1,
      "slide_title": "必须与 deck_pages.txt 里的 data-title 完全一致",
      "slot": "full",
      "style": "engraving",
      "why": "≤40 字：为什么这一页需要图",
      "replace_svg": true,
      "width": 896,
      "height": 512,
      "steps": 6,
      "guidance": 3.5,
      "seed": 20261001,
      "prompt": "英文单段，逗号分隔：主体 → 场景 → 光线 → 镜头/材质 → 风格锚定词",
      "negative": "英文，逗号分隔",
      "caption": "中文图注，≤20 字",
      "credit": "中文来源标注，≤16 字（例如：AI 生成版画示意）"
    }
  ]
}
```
- `width/height` 必须与所选 slot 的尺寸**完全一致**。
- `replace_svg`: `true` 表示替换该页现有的 SVG 图解位（**仅当该页确实有一个纯装饰性的 SVG**；如果不确定，读一下对应 HTML 确认，`lectures/slides/lecture-N.html`）；`false` 表示插入到右栏文字区（half/spot）或顶部横幅（wide），不改动原有 SVG。
- `seed`：每张给一个不同的数字即可，没有先验依据，别假装有。
- `caption` 要像讲员会念出来的一句话（不要"示意图 1"这种）；`credit` 统一风格。
