# 任务：再设计"一张"幻灯片配图（第 2 讲或第 3 讲）

## 已有背景
- 书：《家教会的本体论革命》。四讲讲义已成稿：`lectures/slides/lecture-1..4.html`
- **第 4 讲第 14 页「全餐与彼此等待」已经配了一张照片**（家中长桌、近处空椅与未动的餐具、众人在烛光里等），你可以读它当作风格与版式的参照样例：
  图片位写法是 `<div class="fig plate r"><img src="assets/img/xxx.jpg" alt="…"><p class="cap">…</p></div>`，
  相关 CSS 在 `lectures/slides/assets/deck.css`（`.fig img`、`.fig.plate img`）。
- 本机出图引擎：`FLUX.2-klein 4B` GGUF + 无审查 TE（**小尺寸、快**）。上一条参数：896×512、6 步、guidance 3.5、约 131 秒。

## 你要做的
在 **第 2 讲（`lecture-2.html`）或第 3 讲（`lecture-3.html`）** 里，挑**一个**位置配一张照片级配图，并给出可直接落地的全部设计。

**挑位置的判据（按重要性排序）**
1. 那一页的现有 SVG 是**装饰性/概念性**的，用照片替换不损失信息；**不要**动承载数据或流程的图（如时间轴、箭头流程、对比矩阵、金字塔↔渔网、24 周路线图、三层网络结构这类）。
2. 这张照片能比线条图**多讲出一点东西**（历史现场、光与身体、空间感）。
3. 内容上有书稿支撑（读相关章节）。

## 内容依据
- 第 2 讲对应：第三章、第四章、第五章、第八章、第九章；第 3 讲对应：第六章、第七章、第十章、第十一至十三章。
- 书稿在 `manuscript/`，按需精读相关章（别通读全书，省时间）。

## 硬约束（写参数时必须按这个来）
- 尺寸 **896×512**（16:9 横构图；脚本按 ÷16 建 latent，别用 504）
- 步数 6，guidance 3.5，给 2 个建议 seed
- 总像素 ≤ 0.5MP；**不挂 LoRA**（`old-gods` 风格与主题可能冲突，上一条已验证不用也行）
- 出图画面的**留白要考虑**：图片会在幻灯片里以约 1080px 宽显示，正文栏在其右侧

## 4B 的已知弱点（必须规避）
1. **近景正脸会糊会歪**——主体不要是人脸特写；
2. **手部**多指/畸形高发——不要把手放在前景；
3. **画面里绝对不能有文字**（模型会写成乱码）；
4. 不要现代物件、logo、水印。
上一条之所以成功，是因为**主体是静物、人脸与手都被推到景深之外**——这次也请沿用这个思路（历史场景可让"人"退成远处的模糊身影，把镜头交给空间、物件、光线）。

## 交付格式（紧凑，总长 ≤ 450 字，不含 prompt）
1. **选定位置**：`data-title=` 与"第几页/共几页（DOM 序号按 `.stage > .slide` 数）"，并说明**为什么挑它**、替换后损失了什么。
2. **画面构想**（中文 2–3 句）：拍什么、镜头在哪、它替这张幻灯片多说了什么。
3. **PROMPT**（英文单段，逗号分隔；主体 → 场景 → 光线 → 镜头/材质 → 风格锚定；含 `no visible text`）。
4. **NEGATIVE**（英文）。
5. **参数**：width × height、steps、guidance、2 个 seed。
6. **图注**（中文 ≤ 20 字），**来源标注**（中文 ≤ 16 字；这是 AI 生成图）。
7. **插入片段**：可直接粘贴的 HTML（`assets/img/<文件名>.jpg`，沿用 `.fig plate r` + `.cap` 写法），并说明它替换掉的是哪个块（把被替换块的开头 60 个字符原样贴出来，方便我定位）。

## 约束
- **只做设计**：不要调用生图脚本、不要改任何文件、不要委派子代理、不要用后台任务。
- 不确定就说不确定，别编。节省时间：只读该页与相关章节，别做全书检索。
