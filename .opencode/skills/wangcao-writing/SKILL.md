# 王操文风：中文神学写作与去 AI 味

本 skill 有两层：**复现你的声音**（正面）与**反 AI 味护栏**（负面）。正面定基调，负面清杂音——两者一起用，才是"像你且耐读"。

## 声音（一切的地基）

炉边的牧者-教师。第一人称"我"亮立场（"我以为/我认为"），用"我们"把读者圈进共同体。

敢碰争议、敢评断、愿意得罪人，但落到具体处境时带着牧者的疼与锋。落笔前先问自己：**这篇文要读者看完站到哪个立场上？** 没有明确立场，就是空文。宁可写长一段，不写空一句。

## 结构

- **开篇四式**（选一，别铺陈玄虚）：
  1. 戳常见误解——"许多人以为…，这是极大的误解"；
  2. 反常识提问——如《低情商有"罪"吗？》；
  3. 一个故事/笑话，再抽象出道理；
  4. 个人经历——"我辅导过一位姊妹…"。
- **中段**：先立圣经原则 → 历史/文化语境 → 生活例证 → 实际应用。四者缺一，论证就空。长文用加粗小标题分段（或 `###`），短文用箴言式短行。
- **体裁分档**：论战/神学型按上面走；**实用指南型**（择偶、交友、理财这类）可适度用列表，但**清单只是索引，不能替代论证**——每个 bullet 后必须跟一段完整论述（`6652` 的 `46–97` 做到了，`26–42` 没有）。
- **收束**：呼召/劝勉，或"这点以后再谈"，或反向收束（"我们反对错误的父权制，并非反对父权制"）。**不要总结全文。**

## 句式节奏

长句铺陈 + 三四字短句砸落（"这是历史的定式。""结果圣经就成了心灵鸡汤。"）。一段写完念出来，若一路匀速、句长都在十几字，就是死的——把最长的句子拆开，或在重句后补一个短句让论点落地。

## 金句升华（短文的关键）

一篇短文靠一句金句立住——它同时是 hook、记忆锚点和转发的理由。但"金句不能多"，全篇**一句**。多了互相稀释，读者记不住哪个，hook 反而失效，还露出"每段都想升华"的机器相。

- **只认承重金句**：从论证里长出来、是全文判断的浓缩、删了论点就塌。判据：删掉它，核心判断还完整吗？完整 → 装饰，删。
- **位置**：压在收束最好（`769`"为了上帝的国度，我们愿意千金散尽。"），或开篇做钩子（`734`"活着为了吃饭"）。中段也可以，但要它自己浮上来，不是硬塞。
- **与"不是…而是…"同额**：金句常常就是那唯一保留的承重对偶——两者共享同一个配额。
- **反面**：不靠排比/三连/"不仅…更是"硬堆；不把日常观察拔高成人生大道理（"升华到空"是典型 AI 味）；不是每段都收金句。

## 修辞系统（你的指纹，用足）

- **生活类比**：插座触电讲律法、做菜/屎盆子讲合宜、《指环王》戒指讲权力、父母放权讲民主。抽象命题必须落在一个看得见的物上。
- **历史/政治例子**：孔子·论语、马基雅维利、扫罗与大卫、纳粹、华盛顿。
- **经文**：整段引用，标和合本出处（如"（马太福音 7:21-23 和合本）"），**不可凭记忆转写**。
- **反问**："难道还有比生存更大的问题吗？""究竟谁有权柄判断？"——逼读者自己走到结论。
- **直呼读者**："也许有人会问""你会说"。

## 用词层

半文半白：成语、古文引语用得准（"日光之下无新事""兼听则明""休戚与共""此消彼长"）。神学术语自洽（国度/权柄/属灵/门徒/牧养）。

高频连接是"其实—所以—故此"，**不是**"此外/值得注意的是/综上所述"。

## 反 AI 味护栏

### "不是 X，而是 Y" 配给制（核心闸门）

这是你的思维容器，也是 AI 最爱的句型。**保留，但配给。** 用它之前过三关：

1. **X 是读者真信、或真容易信的旧认知吗？** 是 → 弹药上膛，用得起劲；是临时编的靶子（伪纠偏）→ 必改。没有弹药的枪响不了，只会让读者觉得被冤枉。
2. **这个对比是承重墙吗？** 删了它这段核心论点就塌 → 留；只是顺口 → 改。
3. **配给**：全篇 1 个（最多 2，分散在不同段落），一段之内最多 1 个。`769` 的病就是一段里塞两个。

改法（按优先级）：

1. **设问法**："福音的中心到底是什么？是神国主权在全地的恢复。"
2. **直述法**：删掉否定半句——"Jeff Reed 真正要对比的，是三大教会传统。"
3. **让步法**：先承认 X 有几分理，再推 Y——"争权益不是不能谈，但真正要做的是为真理作见证。"
4. **换语序法**：Y 前置，X 降为"而非 X"从句——"真正的价值使人成长，而不是叫人羡慕。"
5. **具体化法**：抽象对举换动作——"这根本不是解经，是拿圣经为一个目的服务。"

**同族词一起扫**：不仅…更是…、表面…实质…、与其…不如…、不…而…。它们和"不是…而是…"是一家人，单删一个治不了病。

### 高频痕迹清单（命中即处理）

| 痕迹 | 例 | 处理 |
|------|----|------|
| 段末总结句 | 这说明/由此可见/到这里 | 删 |
| 万能开头 | 在当今时代/随着…的发展 | 删，从具体切入 |
| 模糊归因 | 专家认为/研究表明 | 点名或删 |
| 三连排比 | 至关重要、举足轻重、不可或缺 | 换二连或一连 |
| 意义膨胀 | 标志着/见证了/奠定基础 | 降为陈述事实 |
| 假深刻 | 句尾 -ing 式升华 | 删 |
| 过度加粗 / 破折号 | —— | 加粗只在章节级用；列表内关键词改普通字重；破折号换逗号 |
| 强调拐棍叠加 | 重要/需要/必须/实在扎堆 | 删多余，让句意自己扛 |
| 空洞过渡 | 值得注意的是/总而言之 | 删 |

### 做减法，不做加法

流程：**先删至少 20% → 抽象词换具体动作 → 用你自己的样本校准声音 → 整段反查**（"这段哪里还明显像 AI？"再改一遍）。

- 抽象词要问"到底是什么动作"：看到"表达能力"，问是改开头、删废话、还是换例子。
- **禁止为"人味"硬塞语气词、错别字、脏话、假故事、假数据**——"装人味"比 AI 味更尴尬。
- 不过度改：改到自然就停；整体没有明显 AI 味，就不要动。

## 校对（真人指纹，只抓不复制）

你的原稿偶有笔误（"为"误作"为了"、"延申"→"引申"、"站"→"战"、"独身"→"独生"）。这是你真人的证据，但**输出时必须校净，不得模仿**。经文出处、书名、引文尤其要逐条核对（如"雅各布书"→雅各书、引文"智能"→"智慧"、"阿门"→"阿们"）。
