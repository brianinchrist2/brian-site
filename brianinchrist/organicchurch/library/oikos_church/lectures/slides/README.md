## 投屏

1. 电脑与投影设为“扩展显示”（不要镜像）。
2. 在浏览器打开要讲的那一讲，按 `P`，会弹出“讲者视图”窗口，内容是当前页、下一页预览、备注、已放映时长与当前时间。浏览器若拦截弹窗，请允许本页弹出窗口。
3. 把原来的放映窗口拖到投影屏上，按 `F` 全屏；讲者视图留在笔记本屏幕上。
4. 在任何一个窗口里翻页，另一个窗口都会同步，包括分步显示的进度。

`N` 打开的备注面板就在放映窗口里，观众看得见，只适合备课时用。

## 导出 PDF 讲义

用 Chrome 或 Edge 打开某一讲，按 `⌘P` / `Ctrl+P`：

- 目标打印机选“另存为 PDF”；
- 边距选“无”，并勾选“背景图形”；
- 页面尺寸由样式表指定为 1920×1080，每张幻灯片独占一页（`break-after: page`），所有动画在打印时直接显示为最终状态，分步内容全部展开；
- 演讲者备注不会打印。

Safari 对 `@page size` 的支持不完整，导出 PDF 时建议用 Chrome / Edge。

## 视觉与字体

- 配色只用站点 Scriptorium 令牌（`brianinchrist/organicchurch/assets/css/vars.css`）：羊皮纸 `#FAF6EC` / `#F3ECDB`、墨红 `#8A3517`、橄榄绿 `#4A6741`、墨色 `#241B11`、边框 `#E2D8C3` 等。为方便整个目录离线拷走，`deck.css` 顶部复制了一份令牌值；站点改色时请两处同步。
- 字体降级链（不加载任何网络字体）：
  - 正文：`Noto Serif SC → Songti SC → Source Han Serif SC → Georgia`
  - 界面：`Noto Sans SC → PingFang SC → system-ui`
  - 拉丁：`EB Garamond → Noto Serif SC → Georgia`
  - 希腊文：`EB Garamond → Palatino → Times New Roman`。macOS 自带的 Georgia 不含多音调希腊文（ἶ ἰ ἐ ὁ 等），所以希腊文单独走 Palatino。
  - 希伯来文：`Times New Roman → Arial Hebrew`
  没装 Noto / EB Garamond 的 Mac 会自动落到宋体、苹方、Palatino，版式不变。
- 舞台固定为 1920×1080 逻辑像素，按窗口等比缩放（`transform: scale()`）；正文最小 28px，标题 62–104px。

## 动画

- 进场：同页元素依次上移淡入，间隔 90ms。
- 图解：SVG 线条自绘（`pathLength` + `stroke-dasharray` / `stroke-dashoffset`），节点依次弹出；海星断肢、蒲公英种子飘散、单人讲道“盖住”众人发言等是一次性的位移动画。
- 时间轴页：各段条形依次生长，一条游标从 0:00 扫到 1:00。
- 翻页：轻微水平位移 + 淡入淡出。
- 系统设置“减少动态效果”（`prefers-reduced-motion: reduce`）时，所有动画与过渡关闭，页面直接显示最终状态。

## 内容口径

- 页面上的金句按书稿原文照录（制作时用脚本与 `manuscript/` 逐字比对过）；v1 / v2 的“讲员归纳”句（如三讲的收束句、核心追问）在备注里注明“讲员归纳”。
- 经文：v2 标 ⚠、或书稿缺文只有出处的经文，页面上只显示“书卷 章:节”，备注写“⚠ 讲前核对和合本”。页面上出现的经文短句，只限 v2 未标 ⚠ 的少数几处（如可 3:14、约 3:30），仍建议讲前按和合本核对标点。
- 数据与学术引用一律按 v2 第 8.2 节的口径（“估算”“观察”“书稿引述的估计”）。

## 修改

所有内容都在各讲 HTML 里，一页一个 `<section class="slide">`，备注写在该页的 `<aside class="notes">`。图解是内联 SVG：制作时用临时脚本算好坐标后写进 HTML，脚本没有随附。要改图，直接编辑 HTML 里的 SVG 即可。常用页型的 class：`s-cover`、`s-section`、`s-quote`、`s-scripture`、`s-act`、`dark`。
